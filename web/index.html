FRC scouting

Watch the match. Scout every robot.

Paste a recorded FRC match YouTube link. RoboScoutAI reads the scorebug and teams from the video, follows each robot on the field map, and estimates hub, defense, and climb actions. TBA is optional for nicknames.

Tracking & field crop

Paste a Google / Gemini API key below. Mode defaults to Gemini (gemini-3.5-flash with automatic fallbacks). Potato / Auto still work with zero keys via OpenCV.

Use a posted match VOD, not a live stream. Multi-angle broadcasts: top wide-angle drives the top-down map (Depth Anything V2 / BEV for camera angle); bottom side cams feed blue/red scoring & climb cues. If YouTube blocks the cloud download, upload the file you already saved. Scores come from the broadcast overlay when possible.

YouTube download blocked. Upload the MP4/MKV you already downloaded, or export cookies with a browser extension and set YTDLP_COOKIES. Live streams are not supported.
