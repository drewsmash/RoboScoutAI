Paste a recorded FRC match YouTube link or upload a VOD. Tracking uses the top overview camera only — lock the crop, confirm the field map, then review uncertain moments. TBA is optional for nicknames.

Upload skips YouTube entirely. Keep a YouTube URL only if you want title/team metadata from the listing.

Tracking & field crop

Auto runs every available strategy set on the first ~12 s (motion, bumper color, optical flow, YOLO if installed, Gemini/OpenAI if keyed), scores them on robot count, 3v3 balance, persistence, in-field ratio and speed plausibility, and tracks the match with the winner. Modes needing a key or package are marked in the list.

Scout verification uses Laya on this machine when installed (pip install laya — ~10× faster than cloud Jev). Without local weights, an AI Gateway key falls back to typesafe-ai/jev. Multi-view detection runs separately on the overview and each angle shot, then correlates them.

Robot tracking runs only inside the locked overview crop. Side angle shots never create robot identities in this mode. Drag handles appear in Analysis Studio after the first frame.

Use a posted match VOD, not a live stream. Multi-angle broadcasts usually put the correctly oriented field camera on top — leave auto top-camera crop on. If YouTube blocks the cloud download, upload the file you already saved (best fix). For desktop cookies: put cookies.txt next to the EXE, in %APPDATA%\RoboScoutAI\cookies.txt, or set YTDLP_COOKIES. Export with a browser extension such as “Get cookies.txt LOCALLY”. Scores come from the broadcast overlay when possible. Action counts are motion estimates.
