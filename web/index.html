Tracking & field crop

Hybrid cascade: motion/color proposals every frame → SORT multi-object tracking → sparse Gemini/YOLO/OpenAI confirmation. Potato / Hybrid work with zero keys via OpenCV.

Use a posted match VOD, not a live stream. Multi-angle broadcasts usually put the correctly oriented field camera on top — leave auto top-camera crop on. If YouTube blocks the cloud download, upload the file you already saved (best fix). For desktop cookies: put cookies.txt next to the EXE, in %APPDATA%\RamScoutAI\cookies.txt, or set YTDLP_COOKIES. Export with a browser extension such as “Get cookies.txt LOCALLY”. Scores come from the broadcast overlay when possible. Action counts are motion estimates.
